# 会话交接

将当前对话压缩成交接文档，供另一个代理继续工作。保存到操作系统临时目录——不是当前工作区。

## 嵌入式新增段落

除了标准交接内容外，增加：

### 硬件环境

```
**开发板**：<板名、版本>
**调试探针**：<JLink / ST-Link / OpenOCD 适配器>
**已连接仪器**：<逻辑分析仪通道分配、示波器探针>
**供电设置**：<外部电源电压 / USB / 电池>
**接线说明**：<非显而易见的连接、跳线位置>
```

### 烧录与运行

```
**构建命令**：<精确命令>
**烧录命令**：<精确命令 + 探针类型>
**监控命令**：<串口终端设置——波特率、端口、流控>
```

## 标准规则

- 包含"建议技能"段落，推荐下一个代理应调用的技能
- 不要重复其他产物（规范、ADR、工单、提交）中已有的内容——按路径引用
- 脱敏敏感信息（API 密钥、密码、PII）
- 如果用户传了参数，将其视为下一个会话的关注点，相应定制
