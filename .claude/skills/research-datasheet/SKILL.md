# 数据手册研究

启动一个**后台代理**做研究工作，这样你可以在它阅读时继续工作。

## 代理指令

1. **对照第一手来源研究**，按此优先级：
   - 芯片数据手册（电气特性、引脚定义、绝对最大额定值）
   - 参考手册（寄存器描述、外设功能描述、时序图）
   - Errata 表（已知硬件缺陷和厂商 workaround）
   - 应用笔记（ANxxxx——厂商推荐的最佳实践）
   - SDK 源码（厂商实际实现了什么，可能与文档不同）
   - 协议规范（IEEE 802.15.4、BLE Core Spec、ZCL spec、USB spec 等）

2. **每个结论追溯到来源**——不用二手博客、不用论坛帖子（除非它引用了第一手来源）

3. **将发现写入单个 Markdown 文件**

## 输出模板

```markdown

**研究员**：AI 后台代理

| 项目 | 详情 |

| 参考手册 | <文件名 + 章节 + 页码> |

**来源**：<文档名、章节号、页码、URL（如适用）>
```

## 保存位置

匹配仓库已有的研究笔记约定。如果没有，保存到 `docs/research/<主题简称>.md`。

## 用途

研究产出输入到：
- `/grill-embedded-design`——作为决策树的上下文
- `/write-deep-tech-docs`——作为原理级文档的源材料
- `/to-driver-spec`——将实现决策建立在数据手册事实上
