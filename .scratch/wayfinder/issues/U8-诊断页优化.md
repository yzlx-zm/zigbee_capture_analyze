## Resolution (批次 1, 2026-08-10)

**完成**: diag.js 四层 then 嵌套 → 检测器注册表 (数据驱动)。

**实现**:
- `MODULES` 注册表: 每模块 = {api, render(d, checks) -> section html}; L1/L2/L3/L6 四模块
- 主流程: Promise.all + 每模块独立 catch (失败不阻塞, 保留原嵌套链行为) → 统一 renderH + renderOffline
- 新增检测 = 注册表加条目 + 一个 render 函数, 主流程不再改
- 渲染细节零改动 (l1Card/evTable/devLine/summaryCard/renderH 原样保留; checks 收集机制不变)

**验证 (CDP, 第七次素材)**: 重构前后 DOM 对比 — l1cards 8/8, evTables 6/6, conclusions 9/9, divs 3/3, sections 4/4, **bodyText 逐字符一致**。单模块失败路径: catch 在 promise 链尾, Promise.all 不会整体 reject (代码审查确认)。

**自审修正 (2026-08-10, 用户要求自审后追加)**: ⚠️ 初版 `Promise.all` 统一渲染存在**真实退化** — 单模块请求挂起 (无超时) 时整页空白 (CDP Fetch.failRequest 拦截 l6 实测复现: bodyLen=45 页面空白)。修正为**每模块完成即渲染 (渐进, 恢复原嵌套行为) + 15s 超时兜底** (withTimeout); renderOffline 独立请求。修复后验证: 正常路径与基线**逐字符一致**; 失败/挂起路径 (l6 拦截) — 其余 7 卡片立即可见 + 摘要正常 + 无整页错误。
