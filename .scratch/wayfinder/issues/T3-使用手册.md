## 章节结构 (草案, 实现时可微调)

1. **工具简介** — 能做什么 (Zigbee 抓包导入→分析: 诊断/拓扑/报文/节点/AI)
2. **安装与启动** — zip 解压 / 双击 exe / 自动开浏览器 / 版本号 / 关闭=关控制台 / 单实例提示
3. **数据目录说明** — 程序目录 (更新覆盖) vs %APPDATA%\zigbee-analyzer (AI key/日志隔离);
   为什么这样设计 (更新不丢数据)
4. **导入抓包** — 本地路径/拖拽/上传; 小包直接导入; **大包时间窗拆分流程**
   (预扫面板/选窗/拆分子包/下载); 密钥管理; 解析校验报告
5. **诊断页** — 场景 tab 阅读法; 摘要卡; 各检测卡 (命中/未命中/待学习口径); 证据帧跳转
6. **拓扑页** — 链路信息视图; 节点形状/型号/行为状态; 时刻游标看链路变化; 邻居边/图例
7. **报文页** — 过滤 (PAN/节点/时间/类型/未解密开关); 摘要列/路径列/APS Ctr/层级着色;
   详情面板; 事务链跳转
8. **节点页** — 设备身份 (厂商/型号); 控制命令统计; 📄 示例帧解析; ⬇️ 画像导出
9. **AI 侧边栏** — 知识检索 (联网); 对话分析 (key 配置入口/仅存本地说明); 范围确认交互
10. **更新方法** — 新版 zip 覆盖; 数据保留说明; 版本号查看
11. **常见问题 FAQ** — 杀软误报 / 端口占用 / 双击没反应 / 日志位置 / 知识源不可达 /
    未解密包多 (缺 key 说明) / 中文路径
