# 验收标准 — Zigbee 拓扑分析工具

> 确定于 2026-07-21，与用户 Q&A 对齐

---

## 1. 导入页

| 验收项 | 标准 |
|---|---|
| 支持格式 | `.csv` (Ubiqua 导出) |
| 拖拽导入 | 拖拽文件到虚线框 → 解析成功 → 显示统计 |
| 路径导入 | 输入本地路径 → 解析成功 |
| 清除 | 清除按钮 → 所有数据清空 → 可重新导入 |
| 状态持久 | 切走再回来，显示已加载的数据 |

---

## 2. 拓扑页

### 2.1 PAN 过滤
| 验收项 | 标准 |
|---|---|
| PAN 输入框 | 输入 `FEED` → 点筛选 → 只显示 PAN=0xFEED 的节点 |
| 其他 PAN | 输入 `E2DE` → 显示 PAN=0xE2DE 的节点 |
| 协调器 | 每个 PAN 的协调器都是 0x0000，过滤任意 PAN 后 0x0000 始终在顶部 |
| 统计条 | 显示 `显示 X / Y 节点 | 主PAN:0xFEED`，X 随过滤变化 |

### 2.2 树形展示
| 验收项 | 标准 |
|---|---|
| 布局 | 0x0000 在顶部，子节点平铺在下方（保持当前 HTML 树样式） |
| 排序 | 子节点按通信量降序排列 |
| 折叠 | 每个父节点默认展开前 N 个，其余 `...N more` 可点击展开 |
| 全部展开/折叠 | 两个按钮正常工作 |
| 未归类节点 | 默认折叠，点击 ▶ 可展开 |

### 2.3 链路评分表
| 验收项 | 标准 |
|---|---|
| 过滤联动 | 过滤 PAN 后只显示该 PAN 内节点之间的链路 |
| 显示内容 | 链路地址对 + 包数 + 成功率 |

### 2.4 PAN 列表
| 验收项 | 标准 |
|---|---|
| 内容 | 显示 Top 50 PAN ID + 包数 |
| 点击行为 | 点击某行 → 等同于在 PAN 输入框输入并筛选（不跳转） |
| 排序 | 按包数降序 |
