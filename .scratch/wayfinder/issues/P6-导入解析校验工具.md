# P6 — 导入解析正确性校验工具 (后台默认 + 导入页显示)

**What to build:** 导入时后台自动运行的解析器正确性校验, 在导入界面显示校验结果。
保证解析器输出一定正确 (防 0x20/0x38 类误读导致的误判)。

**用户要求 (2026-08-05)**: "非常重要, 一定要保证数据的准确性"

## 对齐决策 (2026-08-05 grilling 确认)

1. **校验标准 (A)**: 
   - pcap 路径: 内部解析 vs tshark 权威 JSON 逐帧对比关键字段 (nwk_src/dst/seq, aps_cmd_id, aps_cluster)
   - cubx 路径: 自洽健康度 (NWK 解密率/APS 命令识别率/pkt_type 未知率/时间单调/地址范围)
2. **粒度 (分层)**: <50MB 全量逐帧; ≥50MB 关键帧全查 (APS命令/NWK命令/Assoc/密钥帧) + 普通帧抽样 200
3. **失败处理 (分类型)**: 
   - 解析错位 (pcap 匹配率<99.5% / cubx 命令识别率低) → **锁定页面** (防误判)
   - 缺 key (cubx 解密率低) → **仅警告** (用户可补 key, 不锁定)
   - 时间/地址异常 → 警告
4. **与现有 verify.py**: **并存分开展示** (数据完整性 vs 解析正确性 两张卡)
5. **工作量**: 1-2 天, 单 ticket 完成不拆分; 对比中发现的字段缺口记入 P1
