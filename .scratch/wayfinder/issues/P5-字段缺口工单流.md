## 工单: ZCL 命令名 FCF 误标 (2026-08-07)

**问题**: Basic 簇 (0x0000) 全局命令 Read Attributes (cmd=0x00, FCF frame type=0) 被误标为 cluster-specific 的 "Reset to Factory Defaults"。根因: `get_command_name` 未接收 FCF frame type, GLOBAL_COMMANDS 与 CLUSTER_COMMANDS[0x0000] 的 0x00 冲突时先查 cluster 表。

**素材实证**: 中继入网抓包(1).cubx — 例证帧 aps_payload_hex `104b0004000000010005000700feff` (fcf=0x10, frame type=0, cmd=0x00 读 Basic 属性 0x0000/0x0001/0x0005/0x0007/0xFFFE)。

**修复** (cubx + pcap 双路径):
- `zcl_defs.get_command_name(cluster, cmd, frame_type)` — frame_type=0→全局表, =1→cluster 表, None/未知→旧回退逻辑 (兼容)
- cubx 路径传 `zcl_fcf & 0x03`;tshark 路径解析 `zbee_zcl.type` (tshark -G fields 确认, 嵌套于 "Frame Control Field" key 下, 与 zcl_direction 同构)
