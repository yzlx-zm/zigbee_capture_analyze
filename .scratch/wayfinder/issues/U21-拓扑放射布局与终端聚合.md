## 实现要点 (总控设计)

### 1. 放射布局算法 (frontend/js/topo.js 新布局函数)
- 圆心 = 协调器 (0x0000); 半径 `r = r0 + depth * dr` (depth 来自现有 BFS)
- **角度分配 (关键, 决定图是否清爽)**: 朴素"同环均分"会导致边交叉混乱 →
  用**子树扇区**分配: 父节点占一个角度扇区, 其子节点在扇区内按子树规模比例分配角度,
  递归下去 → 边不交叉, 类似参考图的整洁感
- 无父证据节点 (depth 99/未知): 统一放最外圈或单独扇区 (与现有一致: 不假装有链路)
- **布局只在节点集合变化时重算**; 时刻游标/时间过滤**只改边样式与节点状态色, 不重算位置**
  (避免拖动时刻游标时节点乱跳 — 这是 U13 时刻游标体验的关键约束)

### 2. 终端聚合
- 路由/协调器 (router/coordinator) 全显示; `end_device` 默认折叠为父节点旁徽章 `×N`
- 徽章点击 → 展开该父节点下的终端 (沿父节点外围小弧排布); 再次点击折叠
- 徽章**反映内部状态汇总** (不丢 U14 信息): 如 `×12 ⚠️2` (2 个重连中) / `×12 ⛔1` (1 个离线)
- **阈值**: 节点总数 <~50 自动全展开 (小网络不打扰); 阈值可后续按实测校准
- **搜索/聚焦某终端** (顶部地址筛选或 🎯 定位) → 自动展开其所在簇并高亮

### 3. 布局切换
- 顶栏加布局选择 (放射 [默认] / 列式 [现有] / 自由 [Cytoscape 力导向])
- 切换不丢当前过滤/时刻游标状态; 切换后 `fit` 视野

### 4. 标签密度自适应
- 标签置于节点**外侧** (沿半径方向, Cytoscape text-halign 按角度象限自适应)
- 密度判定: 节点数 / 环上角度间距 → 超密时只保留路由与协调器标签;
  终端标签与型号进 tooltip (U14 tooltip 已含)
- 缩放联动 (可选, 实现时评估): 放大到一定程度显示更多标签

### 5. 保留项 (不得回归)
形状分类 / 行为状态色 / 型号 / 链路证据边 (父链路·路由路径·下行) / 时刻游标 /
静默节点·邻居边开关 / 图例 / 路由路径链面板 / 统计卡 — 全部保留, 只换位置算法与标签策略

### 算法要点 (依据)
- **层级来源 = 后端 `link_evidence_parent` 的父字段** (全量加载, 与 `curT` 无关) —
  刻意**不用** `cy.edges()` 现画边做 BFS (那是列式布局旧路径, 边集随时刻游标变化 → 节点会跳);
  这是"拖动游标不重算位置"的实现前提 (ticket 关键约束 5)
- 角度 = **子树扇区递归** (权重 = 渲染子树节点数, 子节点按 aid 升序 = 确定性);
  半径 = `max(前环半径 + 120, 环上 gap / 最小相邻角距)` — 解析式一次算出, 无迭代;
  同环相邻角距用角度排序后的相邻对 (含跨 0° 回绕) 求最小
- 孤儿 (无父证据/父不在集/断环) → **最外环独立分环** (不假装挂在树上); 少量孤儿整圈均分
- 断环保护: 证据冲突 (A→B→A) 时环上节点视为无父 (诚实: 不假装层级)
- 徽章: 普通节点 + 特殊样式 (⚠️ 不用 compound — `data.parent` 是 Cytoscape 保留字段, U13 a1d981a 踩坑);
  贴父节点外侧 `父半径 + 节点半宽 + 26`; 簇 **≥2 台**才折叠 (单台聚合无意义);
  标签汇总簇内状态 `×N ⚠️a ⛔b 💤c`; 折叠/展开时父节点扇区权重随之变化 (自平衡)
