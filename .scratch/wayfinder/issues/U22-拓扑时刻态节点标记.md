# U22 — 拓扑时刻态: 节点在游标时刻的证据状态标记

**What to build:** 拓扑页节点显示态从"整段汇总"改为**时刻态** —— 拖时刻游标到 T 时,
显示 T 那一刻每台设备的**证据状态** (正常 / 重入网中 / 已离网 / 无证据), 让"什么时候
出现异常离线 (rejoin/leave)"直接从图上读出来。**只做节点标记** (用户裁定: 不做全局事件带、
不做事件列表面板)。

## 口径定义 (冻结, 本次对齐)

**依据**: `CONTEXT.md` 生命周期状态机 (Association → … → Normal Operation → Leave → Rejoin),
事件全部来自**设备/网关自己发的帧** = 硬证据; 无证据时不下结论。

| T 时刻状态 | 判据 | 词汇 |
|-----------|------|------|
| ✅ 正常 | 有正常证据 (T 附近有帧 / 有 poll 规律) | 默认, 不加任何标记 |
| 🔄 重入网中 | T 之前 **N 秒内**有 rejoin 类事件: Leave(rejoin=1) / Rejoin Req(0x06)/Rsp(0x07) / Device Announce(0x0013) | 事件驱动 (硬证据) |
| ⛔ 已离网 | T 之前最近的生命周期事件 = **Leave(rejoin=0, 永久离开)** 且其后无重入证据 | 事件驱动 (硬证据) — **只有这一档配叫"离线"** |
| ⏳ 无证据 | T 落在证据缺口内 (距最近证据 > 阈值, 且无事件解释) | 证据层事实, 不下"离线"结论 |

- **阈值 (实现时取默认, 按实测校准)**: 事件窗 **N = 60s**; 证据缺口阈值 =
  `max(4×poll间隔, 60s)` (终端, 无 poll 间隔数据时回退 60s), 路由器用 LS 周期基线 (约 15s → 缺口阈值 60s)。
- **删除 `sleeping`** — 无可靠判据 (见上表问题 4); 若用户后续要"轮询变慢"提示, 另开项。
- **合并 `online` 与 `behavior` 为单一时刻态** — 消除问题 2 的矛盾。

## 实现要点 (待认领时细化)

1. **后端** (topology.py / events 端点):
   - 每节点事件时间线: `[{ts, type: leave|rejoin_req|rejoin_rsp|dev_announce, rejoin_flag, request_flag}]`
     (单遍扫描, 与 `_behavior_map` 同源)
   - 每节点证据区间: 任意帧 (src/dst 含自己) 合并 gap>阈值 的区间 → `[{t0,t1}]`
   - **`_behavior_map` 补 PAN 过滤** (问题 5)
   - 保留旧字段以免破坏诊断页/节点页 (逐步切换)
2. **前端 topo.js**:
   - `renderGraph` 按 `curT` 计算每节点状态 → class/图标 (复用现有 🔄/⛔/⏳ 语义)
   - 拖游标时**只改状态与样式** (位置不动 — U21 铁律, 已有 link_snapshots 位置稳定性保证)
   - tooltip 写清"T 时刻: <状态> (证据: Leave @ HH:MM:SS, rejoin=0)"
   - 与现有 U21 聚合徽章协调: 簇内状态汇总取 T 时刻状态 (替换现在的整段汇总)
3. **不做**: 刻度条事件带 / 事件列表面板 / 每节点微时间条 (本轮范围外)

## 验证标准

1. **事件态可复现**: `leave_question_packet.pcap` (有 Leave 战) / `中继入网抓包(1).cubx`
   (有 rejoin + Device Announce) → 拖游标经过事件时刻, 节点状态出现/消失, 与报文页事件徽章
   (U5 同一批帧) 逐帧对得上。
2. **时刻态单调性**: 同一节点在 T 时刻的状态, 与"T 之前最后事件 + 最后证据"手工推算一致 (抽样 10 台)。
3. **无证据态不冒充离线**: 构造/选取"抓包中途开始覆盖"的设备 → 显示 ⏳ 无证据而非 ⛔ 已离网。
4. **回归**: U21 排布/聚合/标签外侧 + 现有拓扑能力 (图例/路径面板/邻居面板/统计卡) 不回归;
   拖游标位置零位移不变。
5. 大素材 (test2 92 节点) 时刻态计算 < 50ms/帧。

## 风险 / 开放问题

- **阈值校准**: N=60s 与缺口阈值需真实素材实测后调 (U21 会话未能定, 用户选择"先实现再调")。
- **Leave(rejoin=1) 的收尾**: 重入网完成的判定用 Device Announce 还是 Rejoin Rsp? 若两者都缺,
  事件窗到期回"正常"是否合适 (可能实际未入网成功) — 实现时按素材定。
- **PAN 过滤修正的连带影响**: `_behavior_map` 加 PAN 过滤后, 现有 behavior 结果会变 (多 PAN 素材),
  需同步核对诊断页/节点页的口径 (P1 级"多 PAN 串网"同源问题)。
- 与 U14 (label/tooltip 状态) / U5 (报文页事件徽章) 的语义一致性: 事件类型名称需统一。

## Resolution (2026-09-24)

**结论**: 节点状态从"整段汇总的 behavior"改为**游标时刻 T 的证据状态**, 视觉复用既有语义
(重连橙 / 离网灰红框 / 无证据虚灰+⏳), 只换判定来源。真实素材验证 **5/5**。

### 判定表 (冻结口径, 实现即此)
| T 时刻状态 | 判据 | 视觉 |
|-----------|------|------|
| 正常 | 其余 (默认, 不加标记) | 无 |
| 🔄 重入网中 | T 前 **60s 内**有 rejoin 类事件: Leave(rejoin=1) / Rejoin Req(0x06)·Rsp(0x07) / Device Announce(0x0013) / Assoc Resp | `rejoining` (淡橙虚线框) |
| ⛻ 已离网 | T 前**最近**事件 = Leave(rejoin=0, 永久离开), 其后无重入证据 | `offline` (灰填充+暗红框) |
| ⏳ 无证据 | T 落在**证据缺口**内 (帧间隔 ≥60s, 含首帧前/末帧后), 且无事件解释 | `moment-silent` (虚灰框+⏳) |
- **协调器豁免**: 它发的 Leave 是踢人指令 (L1-4), 不代表自己离网 → 恒定"正常"
- **事件优先级 > 缺口**: 有 Leave 的节点在其后显示 ⛻ 而非 ⏳ (实测 0x737D ✓)
- 词汇: 从"设备状态"改为**证据状态** (CONTEXT.md 已定义: 无证据只陈述事实, 不下"离线"结论)

### 改动
