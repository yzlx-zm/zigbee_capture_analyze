## 实现要点 (总控设计)

### 1. 后端 — backend/api/files.py /api/packets 列表响应扩展
- 每条加: `aps_counter` / `nwk_relays` (下行) / `summary` (简述) / `layer` (zcl/aps/nwk/mac 层级)
- summary 生成: 精简版语义 (pkt_type + zcl 命令名 + 方向 + 关键标志 Leave rejoin/NS 码),
  参考 export_ai_dataset.packet_summary 简化, 不引入完整 AI 摘要的复杂度
- layer 判定: zcl_cmd_id 非空→zcl; aps_cmd_id/aps_cluster→aps; nwk 命令→nwk; mac 帧→mac
- 上行路径: 可选增强 — 通过 (src,dst) + 时间窗关联 U13 RR 证据; 首版可只做下行
  nwk_relays + 上行关联 RR (U13 已有 route_paths 数据源), 实现时评估复杂度
- decrypted 过滤参数: `hide_undecrypted=1` (默认 0, 前端默认传 1 并带开关)

### 2. 前端 — frontend/js/timeline.js
- **过滤行**: 加"🔒 未解密"开关 (默认开 = 隐藏未解密); 类型下拉保留
- **表格列调整**: 帧号|时间|摘要(原类型)|路径(原安全/状态)|NWK Src|NWK Dst|APS Ctr
- **摘要列**: 渲染 summary (短文本, 过长截断 hover 全显)
- **路径列**: nwk_relays 非空 → `→0xXXXX→0xYYYY`; 空 → `—`
- **层级着色**: summary 列文字+底色按 layer (zcl=绿 / aps=紫 / nwk=蓝 / mac=DataReq 红 else 灰)
- **字段点选过滤 (#1+#B)**: 详情面板字段值 (PAN/Src/Dst/Cluster/命令/端点) 渲染为可点,
  点击 → 填入对应过滤框 (PAN→tl-pan, 节点→tl-node, 类型→tl-type) + 自动"查看"
- **事务链 (#A)**: 详情面板请求帧显示"同事务帧"链接 (aps_pairing 结果, 详情端点已有
  aps_ack_pair) → 点击跳转对应帧 (复用 tlPendingJump 机制) + 表格高亮该事务帧
- 版本号递增 v=YYYYMMDD

### 3. 不动项
- 时间下拉/分页/类型下拉动态化/PAN-节点联动 (U5) 逻辑保留

## 验证标准

1. 未解密: 导入含密文包素材 → 默认列表无未解密帧, 开关关闭后显示
2. 摘要列: ZCL 命令帧显示 `ZCL On/Off C→S`; Leave 帧显示 rejoin 标志
3. 路径列: 中继素材下行 source route 帧显示中继列表; 无路径帧显示 —
4. APS 计数: 列显示 counter, 请求/ack 帧可肉眼对应
5. 层级颜色: 各类帧 summary 列着色正确 (CDP 截图)
6. 字段点选: 详情点 Cluster → 过滤框填入 + 自动查看
7. 事务链: 点请求帧 → 同 counter ack 帧高亮 + 跳转 (CDP)
8. 回归: 现有时间线功能 (跳转联动/详情面板/U15 载荷解析) 不崩; P1/P2 不变
