## 实现要点 (总控窗口设计的落地方案, 已评审)

### 1. 解析层 — `backend/cubx_reader.py`
- result init dict (~429 行 zcl_seq 后) 加: `"zcl_attr_reads": None`
- 新 helper `_parse_read_attr_records(payload, start)` (放 _parse_route_reply 后, 沿用现有手解风格):
  - 结构 (ZCL spec 2.4.2.2.1): 循环 `[attr_id:2 LE][status:1][status==0 时: type:1+data]`
  - 边界防护: 剩余 <4B 停; 记录上限 32; 越界/异常静默停止不 raise
  - value 解码: 0x41/0x42 短字符串 (1B 长度前缀, utf-8 replace)、0x43/0x44 长字符串 (2B 前缀)、单字节数值、2B/3B/4B LE 数值; 其他 type → value=None
  - 返回 `[{attr_id, status, type, value}]`, 无记录返回 None
- ZCL 段挂接 (st_off 块后, zcl_cmd_id==0x01 且 frame type 全局 时): `zcl_attr_reads = _parse_read_attr_records(aps_plain, zcl_off + 3)` (加密帧 base 6 已由现有逻辑处理)
