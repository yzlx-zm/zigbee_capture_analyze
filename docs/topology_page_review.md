## 1. 页面功能地图 (现状清点)

### 1.1 左侧栏 (5 卡片)
| 卡片 | 内容 | 数据来源 |
|------|------|---------|
| 折叠 + 标题 | 节点数 + 主 PAN | events.nodes / main_pan |
| 📊 拓扑统计 | 图节点/图边/数据流/路径(↑探测↓)/LS 邻居/LS 设备 | events |
| 🔍 节点搜索 | 地址/型号/厂商 → 点击进聚焦 | events.nodes |
| 📡 PAN 列表 | 切 PAN | diag/pans |
| 📋 不对称链路 | 邻居不对称 | events (asym) |

### 1.2 工具栏 (2 输入 + 7 按钮 + 1 下拉 + 图例浮层)
PAN 输入 · 地址输入 · 🎯聚焦 · 🔍(定位/筛PAN/全量, 文案随输入变) · 🗑重置 · |
· **布局三档下拉** (U21) · **⊞聚合开关** (U21) · ⋯视图 → ⤢适应 / 📖图例

### 1.3 主图 (Cytoscape) — 视觉编码通道
**节点上同时承载 6 个通道**:
1. 形状 = 设备类型 (六边/菱形/圆/三角)
2. 填充色 = 状态 (淡橙重连 / 灰休眠 / 灰填充+暗红框离线 / U21 徽章紫)
3. 边框 = 路径内外 (紫框 onpath) + 状态叠加
4. 图标 = 🔄重连 / 💤休眠 / ⛻离线 / ⏳链路遗失
5. 文本 = 地址 (+型号, 稀疏时) + 图标
6. 大小 = 密集模式 / off-path 缩小 / 窗内外
7. **徽章 ×N** (U21) = 折叠终端簇 + 簇内状态汇总

**边的 8 种样式**:
| 样式 | 含义 |
|------|------|
| 灰细线 | 数据流 (通信量背景) |
| 彩色实线 (8 色板) | 路由路径 (当前) |
| 天蓝点线 | 父链路 (poll/assoc/rr/down) |
| 灰虚线/残影 | 历史链路 |
| 淡灰虚线 z=-1 | 聚焦时历史叠加 (ghost) |
| 虚线细 | 同源多路径弱化 (route-alt) |
| 洋红粗线 | 路径链 hover / 链路历史高亮 |
| 无色 (off) | routes 面板路径未选中 |

**覆盖层**: ◌待定区标签 (列式) · 聚焦横幅 (标题+退出+🔍报文 + **链路历史时间轴**) · tooltip (U14 全字段)

### 1.4 时间控制条
时刻游标滑块 (单滑块 = 时刻) · 当前时刻文本 · 刻度条 (抓包起止 + 指针)

### 1.5 底部面板 (3 tab)
🛤️ 路由路径链 (路径列表 + hover 高亮 + 点击聚焦) · 🕐 链路历史 (选中节点的链路分段) · 📡 邻居关系 (含不对称)

### 1.6 交互模式 (7 种"改变视图"的机制)
单击高亮 · 双击聚焦 (只看一条链路链) · 顶栏地址定位 · 侧栏搜索定位 · PAN 过滤 · **⊞聚合** (折叠终端) · **布局切换** (三档)

## 2. 结构性问题 (按"是否影响可信/可用"排序)

### P1 — 会让用户误判 (可信度问题)
1. **时间维度的语义不统一**: 边是"时刻态"(游标 T), 节点状态却是"整段汇总"(U22 已对齐待做) — 同屏两套时间语义。
2. **"离线/静默"混用**: 节点写"离线"(末 25% 无帧), 边却按 S3 规则"静默≠离线"保持实线 → 自相矛盾。
3. **8 种边样式里 4 种是"历史/弱化"**: 用户分不清"哪条是此刻真实的链路" (尤其残影边 = 实线同款)。

### P2 — 读不出来 (信息层级问题)
4. **节点 6-7 个视觉通道**: 形状/填充/边框/图标/文本/大小/徽章 — 密度一上来, 读者无法解析 (用户:"效果不是很好")。
5. **状态图标 + 颜色 + 边框三重表达同一件事** (重连/离线), 且三者信源不一致。
6. **默认视图不明确**: 打开第一眼看到的是"全量 + 游标中点 + 可能的待定区堆叠", 没有"当前该关注什么"的引导。

### P3 — 冗余/重叠 (维护与认知成本)
7. **7 种看局部机制**: 聚焦/搜索定位/地址定位/PAN 过滤/聚合/路径面板聚焦/链路历史 — 语义重叠, 用户要记"哪种情况用哪个"。
8. **4 处讲时间**: 游标 · 聚焦横幅时间轴 · 链路历史面板 · (报文页) 事件徽章 — 互不联动。
9. **侧栏 5 卡片 + 底部 3 面板 + 图例浮层**: 一屏 9 块 UI 区域争夺注意力。

### P1 — 性能 (用户新报)
10. **大包导入后首次进拓扑页慢/卡** — 见第 3 节实测。

## 3. 性能实测 (2026-09-21, 81MB / 173 万帧素材)

素材: 81MB / 1,738,481 帧; 方式: CDP 冷启动 + 页面内 fetch/XHR 计时钩子 (u21_perf.mjs)。

| 环节 | 实测 | 说明 |
|------|------|------|
| 页面壳 (DOMContentLoaded/load) | 0.45s / 0.51s | 正常 |
| **`/api/topology/events` 冷** | **19.8s** (首次, 含 timeline 构建) / **12.7s** (换 key 破缓存复现) | **瓶颈: 8 遍全量扫描** |
| **首屏 (导航 → 图出现节点)** | **20.7s** | 用户的"加载久" |
| 并发 `/api/import/status` | **19.8s** (原本 75ms) | **整个后端被阻塞** = 用户的"卡顿" |
| `events` 热请求 | 0.53s / **5.1MB** | payload 过大 (link_snapshots 14441 段未合并) |
| 前端布局应用 | **2~3ms/次** (拖游标 5 帧共 16ms) | 前端不是瓶颈 |
| 切布局三档 | 2~4ms 布局计算 | 同上 |

→ 已开 ticket: `issues/U23-拓扑页大包加载性能.md` (方案 1 预计算 + 3 payload 瘦身 + 5 骨架进度)。

## 4. 可能的收敛方向 (供选择, 未承诺)

- **A. 减通道**: 节点只保留 形状(类型) + 1 个状态通道(颜色), 图标/边框/大小回归中性; 状态细节进 tooltip。
- **B. 时间语义统一**: 全部按 U22 时刻态 (节点+边同源), 历史链路统一"虚线且不入图"。
- **C. 机制收敛**: 聚焦 = 唯一"看局部"入口 (搜索/定位/路径面板都改为"进入聚焦"), 聚合只服务大网络。
- **D. 性能**: events 端点单遍扫描 + 分 PAN 缓存/预计算 (或前端懒加载: 先出骨架再补状态)。
