# U25 — 拓扑页底部面板可收起/可缩放 (扩大绘图区)

**What to build:** 🛤️路由路径链 / 🕐链路历史 / 📡邻居关系 这一栏做成**可收起 + 可拖拽缩放**,
把纵向空间让给绘图区, 让节点/标签在默认视图下更清楚。

**Blocked by:** None | **Status:** done (2026-09-24)

**Assignee:** U25 窗口 (Claude, 2026-09-24)

**Type:** task | **UI 反馈优化** (用户 2026-09-24: "节点展示还是太小了…这一栏做成可以展开和缩放的")

## 实现
- 面板头右侧加 `▾ 收起 / ▴ 展开` 按钮 (`#bp-tog`); 收起时隐藏三个 body (CSS `!important`) 并把面板压到 34px
- 面板上沿加 9px 拖拽把手 (`#bp-resize`): `pointerdown/move/up` 改高度 (40px ~ 72% 视口高),
  拖动中实时 `cy.resize()`, 松手 `cy.fit()` (避免拖动时抖动)
- 高度与收起状态存 `localStorage` (topoBpHeight / topoBpCollapsed), 跨页面/刷新保持
- 收起状态下点任一 tab → 自动展开 (否则"点了没反应")
- 版本 `20260924b`

## 实测 (CDP, `u25_panel.mjs` 7/7)

|----|------|

| 拖拽把手 | 拖高 120px → 面板 340px, 绘图区 477px ✓ 高度写入 localStorage ✓ |
| 异常 | 0 |
