| 关注点 | 现状 | 问题 |

## 拆分维度 (UI 工程 tickets)

### 按页面 (每个页面一个工程单元)
- **U-TOPO**: 拓扑页 (741 行) — 时间控制 (ticket 02 已有 plan) / 渲染性能 / 路径高亮
- **U-TL**: 时间线页 (585 行) — 筛选交互 / 事件标记 / 跳转修复
- **U-DIAG**: 诊断页 (177 行) — L5-L7 卡片扩展 (L1 已对齐) / 设备详情联动
- **U-NODES**: 节点页 (16 行) — 功能补齐 (邻居表/LQI/地址映射)
- **U-IMPORT**: 导入页 (148 行) — 体验优化
- **U-TOPO-TIME**: 拓扑时间维度控制 (独立 plan, ticket 02)

### 按横切 (跨页面的工程单元)
- **U-DESIGN**: 视觉设计系统 (颜色/间距/组件类/状态色规范)
- **U-LINK**: 页面联动 (诊断→拓扑高亮, 时间线→诊断定位)

## 与场景体系的关系

- L1-L7 检测器 → diag.js 卡片 (每新增场景 = 一个卡片切片)
- 检测结果 → 拓扑高亮 (联动)
- 拓扑时间窗口 → 路由变更观察 (L3 场景辅助)

## 优先级 (由用户定, 参考)

1. U-DESIGN (视觉规范) — 横切, 所有页面受益
2. U-TOPO-TIME (时间控制) — 已有 plan, 独立可做
3. U-NODES (节点页补齐) — 16 行, 最小成本
4. U-LINK (联动) — 诊断→拓扑
5. U-TL / U-IMPORT — 体验优化
