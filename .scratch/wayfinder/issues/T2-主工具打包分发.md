## Resolution (2026-08-29, 提交 8c3aab5)

### 实现

**代码层 (数据分层/健壮性)**:
- config.py: `APP_DATA_DIR` 分层 — 打包后 = `%APPDATA%\zigbee-analyzer\`
  (ai_config.json AI key 隔离 + logs 轮转 2MB×3), 开发模式 = 原路径 (行为不变)
- ai_config 路径 3 处统一 `config.AI_CONFIG_PATH` (ai_chat/ai_kb/api.ai, U17 联动)
- __main__.py: 单实例锁 + 版本号控制台标题 + 日志 setup_logging +
  uvicorn 直接传 app 对象 (frozen 下字符串 import 不可靠)
- /api/version 端点 + 前端顶栏版本显示
- ai_kb 离线降级文案 "知识源不可达 (需联网)"

**打包工具**: launcher.py 入口 + build.spec (onedir/datas/hiddenimports/excludes) +
build.py (--version / 清理 / PyInstaller / version.json / zip / 体积清单) +
DIST_README.md (使用/数据目录/更新/杀软/卸载)

**过程中修复 4 坑 (打包实测逐项实锤)**:
1. `from backend import __main__` frozen 下 ImportError → 模块路径导入 `import backend.__main__`
2. **ProcessPoolExecutor (P3 并行解析) frozen 下无 freeze_support() → 大包导入卡 30%**
   (97623 帧拆产物 5 分钟无进展实锤) → launcher 入口 freeze_support()
3. **单实例锁失效**: Windows `os.kill(pid, 0)` 对 sig=0 抛 OSError 被 catch 吞
   → 第二实例覆盖锁文件双开 (PID 46444 实锤) → 改用内核 CreateMutex
4. 版本号仅 total>0 时显示 (空数据实例顶栏无版本) → 无包也显示
